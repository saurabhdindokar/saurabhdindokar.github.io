About

DevOps engineer focused on reliable cloud delivery.

I have hands-on DevOps and infrastructure experience across AWS cloud migration, Kubernetes/EKS delivery, ECS/Fargate migration, CI/CD modernization, monitoring, backup, rollback planning, and production handover.

My DevOps philosophy is practical: infrastructure should be repeatable, releases should be traceable, systems should expose useful health signals, and support teams should never depend only on tribal knowledge. Production Operations

Incident response and reliability experience

Examples of the operational situations I have handled through investigation, recovery, validation, documentation and preventive action.

Kubernetes deployment issue

Investigated rollout status, pod events, logs, configuration and health probes; restored a stable release path and documented validation and rollback steps.

Storage lifecycle recovery

Reviewed backup, snapshot, retention and restore requirements; captured recovery checks and operational ownership for support teams.

Validated process state, dependencies, ports, service logs and health endpoints; corrected startup handling and improved readiness visibility.

Compared release evidence, image and configuration changes, selected the safest rollback path, validated service recovery and improved deployment controls.
