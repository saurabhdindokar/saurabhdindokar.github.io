Production Incidents

Incident experience and prevention mindset

Kubernetes deployment issue

Situation
A rollout did not move forward cleanly after a release.
Investigation
Checked rollout status, pod events, container logs, image tag, environment references, and readiness probe behavior.
Root Cause
Pods were not becoming ready because the application startup and health response were not aligned.
Resolution
Adjusted health-check behavior and documented rollout validation commands.
Prevention
Standardized liveness/readiness probes and added release checklist steps.

Storage lifecycle recovery

Situation
Storage usage and backup retention required review during operations.
Investigation
Reviewed S3 lifecycle rules, backup paths, retention assumptions, and restore expectations.
Root Cause
Retention and restore ownership were not clear enough for support handover.
Resolution
Documented retention, backup validation, and restore verification.
Prevention
Added lifecycle review and restore testing as part of operational runbooks.

Service startup failure

Situation
A service failed to start after configuration or deployment change.
Investigation
Reviewed system logs, environment variables, service dependencies, container startup logs, and recent release changes.
Root Cause
Runtime configuration or dependency readiness caused service startup failure.
Resolution
Corrected configuration and restarted the affected service with validation.
Prevention
Captured startup checks and dependency validation in deployment notes.

Pipeline rollback

Situation
A release needed rollback after validation failed.
Investigation
Reviewed pipeline output, image tags, deployment revision, logs, and health endpoints.
Root Cause
New release did not pass runtime validation.
Resolution
Rolled back to the previous stable image/revision and verified service health.
Prevention
Added rollback commands and validation criteria to the release runbook.

SSL renewal

Situation
Certificate renewal or SSL configuration required planned operational handling.
Investigation
Reviewed certificate expiry, listener configuration, DNS, and application endpoint validation.
Root Cause
Certificate lifecycle needed clearer ownership and tracking.
Resolution
Renewed/validated certificate configuration and confirmed secure endpoint access.
Prevention
Added SSL expiry tracking and renewal checklist.

Production troubleshooting

Situation
Production symptoms required structured triage across infra and application layers.
Investigation
Checked DNS, ALB, target health, pods/tasks, logs, CPU/memory, database connectivity, and recent deployments.
Root Cause
Issue scope required layer-by-layer isolation.
Resolution
Identified affected layer and documented recovery action.
Prevention
Created reusable troubleshooting flow for future incidents.
