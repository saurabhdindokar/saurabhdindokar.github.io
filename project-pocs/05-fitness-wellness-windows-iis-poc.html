This POC excludes private domains, server IPs, database credentials, internal deployment values, and client-specific screenshots.

POC Objective

Create a Windows/IIS deployment and monitoring blueprint for a mixed application stack with .NET hosting, WordPress hosting, database backup planning, CloudWatch dashboard setup, data transfer estimation, and production handover.

Deployment Architecture Diagram

flowchart LR Users[Users] --> DNS[DNS / Domain] DNS --> IIS[IIS on Windows Server] IIS --> DotNet[.NET Core Application] IIS --> WP[WordPress Site] DotNet --> DB[(SQL Server / MySQL)] WP --> DB Server[Windows EC2] --> Agent[CloudWatch Agent] Agent --> CW[CloudWatch Dashboard] Backup[Database Backup Process] --> Storage[Backup Storage] Admin[DevOps Admin] --> PS[PowerShell / Remote Execution] PS --> IIS
